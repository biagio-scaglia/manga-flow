# Web & Editorial Design Guidelines

## Visual Rhythm & Spatial Composition
1. **Asymmetric Editorial Layouts**:
   - Avoid monotonous lists of identical boxes. Alternate between prominent featured titles (Hero spotlight), compact list tiles with volume metadata, and structured catalog matrices.
2. **Typography Pairings**:
   - Display/Titles: Editorial serifs (Playfair Display / Merriweather / Noto Serif) or bold Japanese-influenced grotesques (Cinzel / Plus Jakarta Sans).
   - Data & Metrics: Strict, crisp monospace numbers (`JetBrains Mono` / `Space Mono` / `Roboto Mono`) for chapter numbers, volume counts, percentages, and dates.
   - Body/Text: Highly legible modern sans (Inter / Outfit / Plus Jakarta Sans).
3. **Structured Grid Rhythm**:
   - 8pt / 4pt spatial grid: spacing tokens at 4, 8, 12, 16, 20, 24, 32, 48px.
   - Subtle tactile borders (hairline 0.8px - 1.2px) to give components a crisp, physical printed book feel.
4. **Responsive Breakpoints**:
   - Mobile Compact (< 600px): 1-column list or 2-column grid.
   - Tablet / Web (>= 600px): 3 to 4 column catalog grid with expansive editorial sidebar.
