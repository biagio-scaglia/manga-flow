03 / INGEGNERIA DEL SOFTWARE

CLEAN ARCHITECTURE & ZERO DATI FITTIZI

Costruito per durare nel tempo, con protezione totale dell'integrità dei dati utente.

01

Atomic JSON Storage & Backup .bak

Scrittura atomica a doppio stadio: library.json.tmp → flush su disco → rotazione automatica library.json.bak. Se il file principale dovesse subire una corruzione improvvisa, il sistema ripristina automaticamente lo stato precedente senza alcuna perdita.

02

Deterministic Deduplication Engine

La classe LibraryEntryMerger garantisce l'unicità deterministica per singolo mangaId: tap concorrenti, import legacy o sincronizzazioni multi-istanza confluiscono in una sola entry integra, preservando sempre i progressi più avanzati.

03

AniList GraphQL Live API

Integrazione diretta con l'API ufficiale GraphQL di AniList con rate-limiting dinamico adattivo (HTTP 429 Retry-After), prevenzione risposte stale in volo e cache offline a più livelli.

04

100% Test Suite & Zero Warning

Copertura totale con 28 test automatizzati su regole di business, mutazioni di stato, migrazioni di schema v0 → v1 e test sui widget Flutter, con 0 warning da flutter analyze.
