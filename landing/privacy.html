Informativa sulla Privacy

OFFLINE-FIRST PRIVACY ULTIMO AGGIORNAMENTO: 8 OTTOBRE 2026 • AUTORE: BIAGIO SCAGLIA

01 Titolare del Trattamento & Filosofia del Progetto

La presente Informativa sulla Privacy descrive le modalità con cui l'applicazione e il sito web MangaFlow, ideati e sviluppati da Biagio Scaglia (di seguito, "il Titolare" o "noi"), gestiscono le informazioni e i dati personali degli utenti.

MangaFlow è stato progettato e costruito con una rigorosa filosofia Zero-Knowledge & Offline-First: non raccogliamo, non monetizziamo e non conserviamo alcuna informazione personale su server centralizzati o database proprietari.

02 Dati Personali & Architettura di Memorizzazione Locale

Tutti i dati generati durante l'utilizzo dell'applicazione (inclusi l'elenco dei manga catalogati, i capitoli letti, i volumi posseduti, lo stato di avanzamento e i segnalibri) risiedono esclusivamente sul dispositivo dell'utente (tramite file JSON atomici e database locale protetto).

  • Nessun Account Obbligatorio: Non è richiesta alcuna registrazione tramite email, password o login con social network per utilizzare l'applicazione.
  • Salvataggio Atomico Crash-Proof: I salvataggi avvengono sul file system locale con rotazione automatica del file di backup library.json.bak. Nessun dato lascia il tuo dispositivo.
  • Zero Telemetria: MangaFlow non contiene SDK di profilazione utente, crash analytics invasivi o traccianti pubblicitari di terze parti.

03 Connessioni di Rete & Integrazione API Esterne

L'applicazione effettua richieste di rete verso servizi esterni esclusivamente nelle seguenti circostanze:

  • AniList GraphQL API (https://graphql.anilist.co): Utilizzata in sola lettura per cercare informazioni pubbliche sui manga (titolo originale, autore, copertina ad alta risoluzione, numero di capitoli e volumi). Nessun dato identificativo dell'utente viene trasmesso durante queste chiamate.
  • Download Immagini Copertine: Le immagini delle copertine visualizzate vengono scaricate tramite URL pubblici forniti da AniList e memorizzate nella cache locale del dispositivo per la consultazione offline.
Trasparenza Rete: Anche in totale assenza di connessione internet, l'applicazione continua a funzionare regolarmente con tutte le copertine e i metadati già archiviati nella cache offline.

04 Cookie & Tracciamento Web sul Sito Statico

Il sito web di presentazione e simulazione di MangaFlow:

  • Zero Cookie di Profilazione: Non utilizza cookie di tracciamento commerciale, cookie di terze parti né pixel pubblicitari (Meta Pixel, Google Ads, etc.).
  • Memorizzazione Locale (localStorage): Utilizza la memoria locale del browser esclusivamente per ricordare la preferenza visiva dell'utente (tema scuro Night Ink o chiaro Washi Paper).
  • Hosting GitHub Pages: Il sito è ospitato sull'infrastruttura statica sicura di GitHub Pages. I log di accesso HTTP di base sono gestiti da GitHub Inc. nel rispetto della propria informativa sulla privacy globale.

05 Diritti dell'Utente (GDPR / Regolamento UE 2016/679)

Poiché i dati sono conservati unicamente all'interno della memoria locale del tuo smartphone:

  • Controllo Totale & Accesso: Puoi esportare, consultare e modificare il file library.json in qualsiasi momento.
  • Diritto di Cancellazione Immediata: Disinstallando l'applicazione o svuotando i dati dell'app dalle impostazioni del dispositivo, tutti i dati archiviati verranno eliminati istantaneamente e in modo irreversibile.
